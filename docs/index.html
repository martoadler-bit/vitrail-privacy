Vitrail Support

Build rhythms by connecting sounds on a canvas. Each link sets how many sixteenth notes a hit travels before it plays the next sound.

Play your first network

Choose a factory scene and press Play. Select a node to change its sound, pan or routing. Use Link to connect a source to its destination.

Use Vitrail in a host

Add Vitrail as an AUv3 instrument on a MIDI track. Play MIDI notes to trigger nodes. Save your host project to recall the network.

Save a pattern or share audio

In the standalone app, save a patch as JSON to edit it later. Use audio export to render a pattern to a file.

Get help

Email martoadler@gmail.com. For playback issues, include your device, iOS version, and the host name if you use AUv3.
